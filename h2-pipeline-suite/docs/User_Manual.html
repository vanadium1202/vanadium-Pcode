User manual · version 1.1

H2 Pipeline Suite

A workbook for moving hydrogen by pipeline: repurposing natural-gas lines, designing new hydrogen lines, blending hydrogen into natural gas, and blending in city gas networks — with safety, integrity, repair and specification tools.

Please note. IGEM/TD/1 Supplement 2 and CSA Z662:23 Clause 17 content is summarised from public sources; the IGEM factors for Classes S and T and the CSA location factors are marked “verify” in Code tables. This is a screening and option-study tool. Code values (ASME B31.12, B31.8 and others) were transcribed from public sources and can be edited. Check them against your licensed standards. Final design, MAOP and safety decisions need review by a competent engineer.

1. Getting started

  1. Copy H2_Pipeline_Suite.html (and User_Manual.html) to any folder on your laptop.
  2. Double-click H2_Pipeline_Suite.html. It opens in your normal browser — Chrome, Edge, Firefox or Safari, on Windows or Mac.
  3. That is all. Nothing to install, no internet needed. (With internet the page uses nicer fonts; without it, it uses your system fonts.)

The tool opens with a complete synthetic example — a 24-inch X52 natural-gas trunkline, 120 km long, MAOP 70 barg — so every module shows results straight away. Replace the example values with your own.

Your inputs are saved automatically in the browser. To keep them safely, or move them to another computer, use Files & data → Save project (see section 17).

2. The screen

  • Left rail — the list of modules, grouped: Setup, Transport routes, Integrity, Safety, Specifications, Data & QA. On a phone it becomes a drop-down list.
  • Top bar — the project title and the theme button (system / light / dark).
  • Toolbar under each module title:
    • Fill from project copies the shared pipeline data (diameter, wall, grade, MAOP…) from the Project module.
    • Reset inputs returns the module to its example values.
    • Export report (.html) and Report for Word (.doc) save the inputs, results and the references used.
    • Results table (.csv) saves the main results table for Excel.
  • Inputs on the left, results on the right. Results update as you type.
  • Status chips: green OK, amber Review, red Fails / not suitable.
  • Reference tags such as R2 appear next to results. Click one to open the reference list at that source.

4. Project & scenario

Enter the project title and the existing pipeline: outside diameter, wall thickness, grade, seam type, year, segment length, MAOP, minimum delivery pressure, temperature, location class, roughness and efficiency factor. These are the “shared data” other modules can pull in with Fill from project.

The results compare the three routes for this line on one table: natural gas today, the blend at the existing MAOP, and 100 % hydrogen after re-rating under ASME B31.12 Option A and Option B. “vs NG” is the energy the line can carry compared with natural gas today.

5. Gas properties

  1. Pick a preset natural gas (e.g. RLNG typical) or type your own composition in mol %. It does not need to add up to 100 — it is normalised.
  2. Set the hydrogen % to study, the line pressure and temperature.
  3. Choose the metering reference (15 °C ISO, 0 °C normal m³, or 60 °F) and the energy basis (HHV or LHV). These settings apply to the whole tool.

You get heating values, Wobbe index, relative density, compressibility Z, density, viscosity, flammability limits and CO₂ per GJ, side by side for natural gas, the blend and pure hydrogen, plus trend charts.

Z calibration multiplier. Z comes from the Peng–Robinson equation with a volume correction; it is within about ±1.5 % of GERG-2008 for 10–100 bar and 0–40 °C. If you have an AGA 8 or GERG value for your gas, set the multiplier so the tool matches it.

You can import or export the composition as a CSV file (two columns: component, mol %).

6. Repurposing an existing pipeline for 100 % hydrogen

This module answers two questions: is the steel suitable? and what pressure is allowed?

Inputs

  • Service & pipe — hydrogen %, dimensions, grade, seam, existing MAOP, location class, design temperature and the design code / method:
    • ASME B31.12 Option A — prescriptive, uses the material performance factor Hf.
    • ASME B31.12 Option B — performance-based, needs hydrogen fracture tests (KIH ≥ 55 MPa√m).
    • IGEM/TD/1 Edition 6 Supplement 2 (UK) — design factor capped at 0.5, Hf applied to grades above L360, fracture-toughness testing in hydrogen required, blends above 10 mol % treated as pure hydrogen.
    • CSA Z662:23 Clause 17 (Canada) — requires an engineering assessment rather than fixed limits. The tool uses the lower of the Z662 design factor (F × location factor) and the B31.12 Option A factor that Z662 cites as guidance.
  • Material test data — from mill certificates, field hardness surveys or cut-outs: maximum yield/tensile strength, hardness of base metal and welds, hard spots found by ILI, Charpy energy, DWTT, and KIH if tested.
  • Chemistry — the tool calculates CE(IIW) and Pcm.
  • Condition & history — cracks, dents, metal loss, girth-weld practice, pressure-test ratio, CP potential and pressure cycling.

Results

  • MAOP re-rating: B31.8 value for gas, then B31.12 Option A and B, IGEM/TD/1 Supplement 2 and CSA Z662 Clause 17, the derating in %, hydrogen partial pressure and the energy capacity after conversion.
  • Code requirements table: side-by-side requirements of ASME B31.12, IGEM/TD/1 Supp 2, CSA Z662:23 and EIGA 121/14 (design factor, Hf, hardness, CE, toughness and fatigue testing, repurposing), with checks against your data.
  • Screening table: about 20 checks (hardness, hard spots, seam, grade, chemistry, toughness, KIH, cracks, dents, girth welds, test record, CP, stress level, cycling) with a status, the criterion, the reference and the action needed.
  • Recommended programme: the actions to close every amber and red item before conversion.
Example. The synthetic 24" × 9.5 mm X52 line at MAOP 70 barg in Class 1 Div 2 re-rates to about 56 barg under Option A (design factor 0.5, Hf = 1), a 20 % derating. Option B allows 70 barg if KIH ≥ 55 MPa√m is demonstrated by testing.

7. Blending hydrogen in a natural-gas transmission pipeline

Use this to find the energy effects of a blend in an existing line.

  • Comparison basis: Same energy delivered (you enter the demand in MW — the tool finds the flow and inlet pressure needed) or Same pressures (the maximum the line can carry).
  • Compressor driver: gas turbine (fuel taken from the line) or electric motor, with its efficiency.
  • Leakage: your baseline natural-gas leakage as % of throughput and the leak type.

What “energy loss” means here. The energy a compressor station must spend to push the gas through the segment (to restore the pressure drop), divided by the energy delivered. Hydrogen-rich gas needs more volume for the same energy, so compression energy rises with the blend. The tool also shows leakage energy, line-pack energy, outlet velocity against the erosional limit, Wobbe change and the hydrogen partial pressure the steel sees.

The code & regulatory thresholds table shows what applies at your blend level: IGEM (above 10 mol % = pure-hydrogen rules), CSA Z662 Clause 17 (any hydrogen = engineering assessment), ASME B31.12, UK GS(M)R (0.1 mol %), the Alberta 20 % distribution recommendation and India PNGRB.

The tolerance table lists typical maximum blend levels for components and end users (pipelines, PE pipe, appliances, meters, gas chromatographs, CNG cylinders, gas turbines, storage), including India’s PNGRB preliminary limits.

8. New hydrogen pipeline design

  1. Enter the duty: hydrogen %, design flow (tonne/day, kg/s, MW or MMSCMD), length, inlet and design pressure, minimum delivery pressure and source (electrolyser/plant) pressure.
  2. Enter the mechanical design basis: design code (B31.12 Option A or B, IGEM/TD/1 Supp 2 or CSA Z662 Clause 17), location class, grade, design and minimum temperatures, corrosion allowance, maximum D/t and minimum wall.
  3. Enter the hydraulic criteria: roughness, efficiency, maximum velocity. Leave “Force NPS” at 0 to let the tool pick the smallest feasible size.

The size screening table checks every standard NPS: required and selected wall, outlet pressure, velocity, hoop stress and steel tonnage. The highlighted row is the selected design. Below it you get MAOP, hydrotest pressure, line pack, the Charpy energy needed to arrest a running ductile fracture (Battelle two-curve method), compression power from the source pressure and a pressure profile.

The selected design is passed automatically to the Line pipe specification and Instruments & equipment modules.

9. CGD blending & Wobbe index

For city gas distribution networks. Choose the hydrogen % and a Wobbe acceptance range (UK GS(M)R, CEN EN 16726, EN 437 family, or your own), and the appliance tolerance band (± % about today’s Wobbe).

Why Wobbe matters. The heat input of a burner at a fixed nozzle and supply pressure is proportional to the Wobbe index. Hydrogen lowers both the heating value and the density, so Wobbe falls more slowly than heating value — about −5 % at 20 % H2 for RLNG.

Results: Wobbe and its change, heat-input change, extra volume needed for the same energy (important for volumetric billing), network energy capacity, burning velocity (flash-back tendency), CO₂ reduction, the highest blend inside the selected range, a chart with limit lines, and CGD component limits.

10. ILI & defect assessment

  1. Click Download template to see the column layout, or Load synthetic sample to try it.
  2. Prepare your ILI feature list in Excel with the same columns and save as CSV. Click Upload ILI CSV.
  3. Set the assessment pressure (the hydrogen MAOP from the Repurposing module) and the design factor.

Each anomaly is assessed: metal loss by Modified B31G (failure pressure, safe pressure, ERF), cracks by stress-intensity factor against KIH, dents against a hydrogen screening limit (2 % OD by default) and the B31.8 rules, hard spots (always repair) and laminations (check for blistering). A summary shows how many need repair before hydrogen service.

11. Fatigue & fracture

Hydrogen makes cracks grow faster under pressure cycles. This module grows a surface flaw until it reaches the critical size.

  • Enter the flaw (depth and length — e.g. the ILI detection threshold), KIH, hydrogen % and the loading.
  • Loading: either a simple daily cycle (max/min pressure, cycles per day) or a SCADA pressure history. Upload a CSV of time (hours) and pressure (barg); the tool counts cycles by the rainflow method (ASTM E1049). Generate synthetic history creates a 60-day example.
  • Results: life in hydrogen and in air, allowable life (calculated life ÷ 2), critical flaw depth, re-inspection interval, crack-growth chart and the design curves.

The hydrogen curves follow ASME Code Case 2938 with an optional pressure correction for the low-ΔK part. The constants are editable in Code tables.

12. Repair of hydrogen pipelines

Pick the defect type, hydrogen %, pressure during repair, whether the line is live, wall thickness and defect depth. Enter the steel chemistry, heat input and consumable hydrogen level.

You get a ranked list of repair methods (recommended / conditional / not recommended) with hydrogen-specific notes, weldability indices, the minimum preheat by EN 1011-2, hardness limits, warnings (e.g. live welding on hydrogen, burn-through risk), and the full method matrix.

13. Operations & integrity

For an isolation section between block valves: gas inventory, blowdown time and peak vent rate, energy vented, greenhouse effect of venting, nitrogen purge quantities, and an integrity-management programme comparing natural-gas and hydrogen practice.

14. Hydrogen safety — leak and rupture

  1. Enter pipe size, operating pressure, temperature and hydrogen % (works for NG, blends and pure hydrogen).
  2. Leak: hole size (and extra sizes for a sensitivity table), discharge coefficient, radiant fraction (0 = automatic), transmissivity, exposure time and TNT yield.
  3. Rupture: the full-bore, double-ended case is calculated automatically. The delayed-ignition explosion estimate needs a release time and flammable fraction — these are assumptions, so test a range.

What you get

  • Leak: release rate, flame length, distances to each thermal-radiation level (1.58 to 37.5 kW/m²), distance to LFL and ½ LFL (unignited gas cloud), flammable mass, TNT-equivalent mass, overpressure distances, and 1 % / 50 % fatality distances.
  • Rupture: potential impact radius (PIR) from the model and from the code constant (0.69 for NG, 0.47 for H2), thermal-radiation radii and overpressure distances.
  • Safe-zone diagrams for leak and rupture, and a table of hydrogen hazard properties.
Using the zones. A common approach: emergency exclusion at the 4.73 kW/m² contour (people can escape), public evacuation to 1.58 kW/m², no ignition sources inside ½ LFL. Wind, terrain and buildings are not modelled — use detailed software (e.g. HyRAM+, PHAST) for the final safety study.

15. Line pipe specification

Creates a purchase specification for new hydrogen line pipe, supplementary to API 5L / ISO 3183 PSL2. Defaults come from the New H2 pipeline design. Edit any requirement:

  • Pipe data, manufacturing process and steel processing route.
  • Chemistry limits (C, Mn, P, S, micro-alloys, CE(IIW), Pcm).
  • Mechanical limits: Y/T, maximum yield, hardness (≤ 250 HV10 body, ≤ 235 HV10 weld/HAZ), Charpy, DWTT.
  • Hydrogen qualification tests: KIH, fatigue crack growth and J-R in hydrogen, HIC test, microstructure.
  • Coatings.

A consistency check flags conflicts (e.g. Charpy lower than the fracture-arrest requirement). Export the specification as HTML or as a Word file (.doc), then finish it in Word.

16. Instruments & equipment

Choose an item from the list: mainline valve, PSV, compressor, ultrasonic meter, gas chromatograph, pressure transmitter, gas detector, flame detector, pig trap, insulating joint, cathodic protection, odorisation, seals, hazardous-area electrical equipment, leak detection. Each datasheet is filled from the design and every line is editable. Hydrogen-specific requirements and the standards are listed.

For the PSV, the tool sizes the orifice by API 520 (gas, critical flow) and selects the API 526 letter. Export one datasheet or the full package (HTML or Word).

17. Files, upload and download

Project file

  • Save project (.json) — everything: all module inputs, composition, ILI listing, pressure history and code tables. Tick “Include document-library files” to pack your documents too.
  • Open project — loads a saved file (on any computer).
  • New project — clears inputs (asks you to confirm).

Templates and exports

Templates for ILI listings, pressure histories and compositions; code tables as JSON; and “All module results (.csv)” — one CSV with every module’s main table.

Document library

Add any files (PDF, Excel, images, drawings…) with a note and the module they relate to. They are stored in this browser on this computer. Download or remove them at any time.

If you open the tool inside a viewer that blocks downloads (for example an embedded web page), a message offers Copy content: paste it into Notepad or TextEdit and save with the file name shown. Opening the HTML file directly from your disk has no such limit.

18. Code tables

All code values used by the calculations are here and editable: the B31.12 Hf table, design factors by location class (B31.8, B31.12 Option A and B, IGEM/TD/1 Supp 2 — mapped Class 1→R, 2→S, 3/4→T — and the CSA Z662 location factor), hydrotest ratios, screening limits (hardness, CE, S, P, Charpy, KIH, stress levels, dent limits, CP limit), fatigue-crack-growth constants and rupture-fire parameters. Changes apply immediately to every module and are saved with the project. Reset all tables restores the defaults.

19. Verification

The Verification module runs 19 test cases against published values (ISO 6976, EN 437 test gases, API 520 example, ASTM E1049 example, ASME B31.8S and B31.12 PIR constants) an independent Python calculation (with GERG-2008 compressibility) and hand checks of the IGEM and CSA design pressures. All pass at the stated tolerances. Re-run it after editing code tables.

21. Troubleshooting

ProblemWhat to do
“Calculation could not be completed”An input is zero, negative or unrealistic (e.g. wall thickness 0, minimum pressure above inlet). Correct it, or press Reset inputs.
“infeasible” in the size tableThe pressure drop is too large for that size at the design flow; a larger size is needed.
Hf shows “—”The pressure or grade is outside the Hf table (above 3000 psig or above X80). Use Option B or extend the table in Code tables.
My inputs disappearedBrowser data was cleared, or you opened the file in a different browser. Always keep a saved project file.
Upload did nothingCheck the file is CSV (not .xlsx) and has the expected columns; see section 20.

22. Glossary

BTCMBattelle two-curve method — checks whether a running ductile fracture will arrest.
CC2938ASME Code Case giving fatigue-crack-growth design curves for steels in hydrogen.
ERFEstimated repair factor = operating pressure ÷ safe pressure. ≥ 1 means repair.
HfMaterial performance factor in ASME B31.12 Option A; reduces allowable stress for higher grades and pressures.
KIHThreshold stress-intensity factor for hydrogen-assisted cracking, measured in hydrogen gas.
LFLLower flammability limit (4 % for hydrogen, 5 % for methane).
PIRPotential impact radius — distance at which a rupture fire gives 15.8 kW/m².
pH2Hydrogen partial pressure = total pressure × hydrogen fraction.
Wobbe indexHeating value ÷ √(relative density); measures interchangeability of gases in burners.
